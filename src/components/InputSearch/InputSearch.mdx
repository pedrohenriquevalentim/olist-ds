# InputSearch

Campo de busca com borda pill e botão ícone de ação.

## Import

```tsx
import { InputSearch } from '@pedrohenriquevalentim/olist-ds';
```

## Uso básico

```tsx
const [value, setValue] = useState('');

<InputSearch
  label="Pesquisar pedido"
  placeholder="Digite o número do pedido"
  value={value}
  onChange={setValue}
  onSearch={() => console.log('buscar:', value)}
/>
```
